# Laboratório de Engenharia de Dados

Repositório destinado ao desenvolvimento e organização das atividades práticas da disciplina de **Engenharia de Dados**, da **CESAR School**.

## Sobre o repositório

Este repositório funciona como um laboratório para aplicação dos conceitos estudados ao longo da disciplina, incluindo práticas relacionadas a arquitetura e processamento de dados, infraestrutura, cloud computing, pipelines e outras ferramentas utilizadas na área de Engenharia de Dados.

A organização das entregas será feita por meio de **Pull Requests (PRs)**.

Cada atividade proposta durante a disciplina será desenvolvida separadamente e submetida em uma PR própria, permitindo acompanhar de forma clara a evolução das implementações e das decisões realizadas durante o semestre.

## Organização das atividades

O fluxo utilizado será:

```text
main
 ├── branch/atividade-01
 │     └── Pull Request #1
 │
 ├── branch/atividade-02
 │     └── Pull Request #2
 │
 ├── branch/atividade-03
 │     └── Pull Request #3
 │
 └── ...
```

Para cada nova atividade:

1. Será criada uma nova **branch** a partir da `main`;
2. A atividade será desenvolvida e documentada nessa branch;
3. As alterações serão enviadas para o GitHub;
4. Será aberta uma **Pull Request** correspondente à atividade;
5. Após a conclusão, a PR poderá ser integrada à branch `main`.

## Estrutura

A estrutura do repositório poderá evoluir conforme as atividades propostas durante a disciplina.

```text
Laboratorio-Engenharia-de-Dados/
│
├── README.md
│
└── atividades/
```

Cada atividade poderá conter seus próprios códigos, configurações, scripts, arquivos de infraestrutura e documentação.

## Objetivo

O objetivo deste repositório é registrar o desenvolvimento das atividades da disciplina de forma organizada e versionada, permitindo acompanhar a evolução dos conhecimentos e das práticas relacionadas à **Engenharia de Dados** ao longo do semestre.
